Test Meta Tags Page

Halaman ini digunakan untuk testing meta tags Open Graph dan Twitter Card.

Tools untuk Validasi Meta Tags:

  • Facebook Debugger
  • Twitter Card Validator
  • Open Graph Checker

Langkah Testing:

  1. Deploy aplikasi ke server dengan domain publik
  2. Ganti URL di meta tags dengan domain Anda
  3. Copy URL halaman ini dan paste ke tool validasi
  4. Verifikasi bahwa gambar muncul di preview

Catatan Penting:

  • Meta tags hanya berfungsi jika halaman dapat diakses dari internet
  • Gambar harus memiliki URL publik
  • Gunakan URL absolut untuk gambar
  • Format gambar yang didukung: JPG, PNG, WebP
